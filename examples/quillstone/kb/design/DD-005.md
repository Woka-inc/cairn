# DD-005: Configuration and command surface

## Context

Users could not tell which of several sources set a value, especially in containers.

## Decision

Settings resolve in the order defaults, file, environment, flags; each value records its origin.

## Consequences

- `qs explain-config` can always say where a value came from.
- New subcommands need a design note.

# DD-007: Columnar interop

## Context

Users exchange data with Arrow-based tools and paid for a full copy on every boundary.

## Decision

Batches use Arrow-compatible layouts so that conversion is zero-copy when buffers are aligned.

## Consequences

- The Arrow bridge can share buffers.
- Some internal layouts become fixed.

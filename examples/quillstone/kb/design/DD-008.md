# DD-008: Telemetry conventions

## Context

Each module named its metrics differently, so dashboards needed per-module queries.

## Decision

Metric, span, and log field names follow one naming scheme with the stage name as a common label.

## Consequences

- One dashboard works for every pipeline.
- Renaming a metric is a breaking change.

# DD-001: Error model

## Context

Early versions threw plain errors with free-text messages, so retries and alerts matched on message text and broke on rewording.

## Decision

All errors are `QsError` values with a stable `code`, a `transient` flag, and an optional `cause`.

## Consequences

- Retry logic reads the `transient` flag instead of parsing messages.
- Codes are part of the public API and follow semantic versioning.

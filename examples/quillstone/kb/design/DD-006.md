# DD-006: Adapter contract

## Context

Adapters written by different teams handled batching and errors differently, which made sources hard to swap.

## Decision

Every adapter implements four methods, declares checkpoint support, and wraps failures in `QsError`.

## Consequences

- Sources can be swapped without changing transforms.
- The base class carries most of the shared code.
